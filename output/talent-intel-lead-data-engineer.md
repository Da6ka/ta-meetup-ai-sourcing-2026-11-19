# Карта рынка: Lead Data Engineer, Valiotti Data

19 ноября 2026. Исследование в Codex по [инструкции Talent Intel](https://github.com/SriniGundelli/talent-intel/blob/main/skills/talent-intel/SKILL.md).

Консалтинг по данным для международных клиентов Удалённо из любой страны, full-time B2B От 5 лет в DE, senior или lead. Самостоятельный выбор архитектуры и её защита перед клиентом. SQL, Python, BigQuery, Airflow 2, Claude Code в реальном проекте, английский B2+. До 4 000 EUR gross в месяц, full-time B2B.

## Компании-доноры

- Future Mind (Польша). Для клиента из Северной Европы команда строила платформу данных на BigQuery, Dataflow и Cloud Composer. В вакансии указаны SQL, Python и работа с заказчиком. [Вакансия](https://jobhunt.pl/oferta/remote-experienced-data-engineer-with-gcp-future-mind-7917a8)

- **Datatonic.** Миграция клиентского хранилища с Netezza на BigQuery. В кейсе описаны модель данных, ETL и обучение команды клиента. [Источник](https://cms.datatonic.com/app/uploads/2020/09/Datatonic-On-Prem-to-Cloud-Data-Warehouse-Migration-Whitepaper.pdf)
- **Devoteam.** Для сети магазинов e5 команда Devoteam переработала архитектуру приложений и потоков данных. Клиент объединил данные о покупателях, товарах и бизнесе в BigQuery. [Источник](https://cloud.google.com/customers/e5)
- **DoiT.** Для Huq перестроили пайплайн на Google Cloud с Dataflow, BigQuery и Cloud Composer. [Источник](https://www.doit.com/customers/huq)
- **Thoughtworks.** Модернизация платформы данных авиакомпании. Смежный пул для проверки клиентской архитектуры; владение BigQuery нужно подтвердить. [Источник](https://www.thoughtworks.com/en-us/clients/data-platform-modernization)
- **Searce.** Для Cardinal Group команда Searce перенесла хранилище с PostgreSQL на BigQuery, адаптировала SQL и проверяла целостность данных. [Источник](https://cloud.google.com/customers/cardinal-group)

## Где ещё искать

- Консультанты BigQuery. У Datatonic, Devoteam и Searce есть примеры миграции клиентских платформ данных. Уточните, за какие решения отвечал конкретный инженер.
- Apache Airflow Meetups. Проект публикует программу сообщества. В докладах о production-пайплайнах можно искать примеры решений и оркестрации. [Сообщество Apache Airflow](https://airflow.apache.org/meetups/)

## Оплата

Сравнение предполагает, что 4 000 EUR включают вознаграждение до личных налогов, а возможный НДС начисляется отдельно. ## С чего начать поиск

Начинаем с Future Mind. Есть клиентский проект на нашем стеке, а бюджет попадает в опубликованную вилку смежной роли. Среди нынешних и бывших инженеров ищем Senior или Lead, которые сами выбрали архитектуру и защитили решение перед клиентом. В первом сообщении называем потолок. Если причина отказов в оплате, возвращаемся к заказчику с ответами кандидатов.

- `site:linkedin.com/in "Future Mind" "Senior Data Engineer"`
- `site:linkedin.com/in "Future Mind" "Lead Data Engineer"`
- `("Senior Data Engineer" OR "Lead Data Engineer") AND BigQuery`

## Ограничения

Ставка Lead в Future Mind неизвестна. Вилка относится к вакансии Mid. Опыт конкретного инженера, включая работу с Claude Code, и его ожидания проверяем отдельно. Для Datatonic, Devoteam и DoiT сопоставимой публичной B2B-вилки в этом поиске не нашли.
