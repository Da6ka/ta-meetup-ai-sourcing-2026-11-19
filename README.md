# ИИ-сорсинг кандидатов

Материалы выступления Дарьи Ивановой на TA Meetup 19 ноября 2026 года. Поиск разбирает вся группа. Дарья показывает запросы и профили на одном экране, участники предлагают решения вслух.

## Для ведущей

- [Сценарий доклада и мастер-класса](plan-ta-meetup.md)
- [Структура презентации и текст для показа в Codex](struktura-prezentatsii.md)

## Для участников

- [Скачать бриф с QR-кодами для печати](output/pdf/ta-meetup-brief-a4.pdf). Формат A4, масштаб 100%, двусторонняя печать с переворотом по длинной стороне.
- [Бриф, запрос для ИИ и ссылки для самостоятельного поиска](materialy-uchastnikam.md)

Чтобы обновить PDF после правки брифа, запусти из корня проекта `python3 scripts/build_handout.py`. Скрипт использует ReportLab и шрифты Arial и Georgia из macOS.
