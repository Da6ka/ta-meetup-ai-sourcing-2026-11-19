# Как написать свой первый скилл для сорсинга

Скилл хранит ваши инструкции для повторяющейся задачи. Для первой версии возьмите один момент, когда обычно приходится поправлять ИИ. Например, после просьбы расширить поиск модель добавляет термин, который приводит слишком много людей с другим опытом.

## Алгоритм

1. **Выберите один шаг.** Закончите фразу «Когда мой запрос пропускает подходящих людей, я прошу ИИ…». Назовите результат, который хотите получить на этом шаге.
2. **Разберите удачный пример.** Возьмите обезличенный бриф, исходный запрос и вашу правку. Что вы заметили? Как решили, что второй вариант лучше? Запишите это своими словами.
3. **Выпишите вход и действия.** Что вы будете давать каждый раз? Что ИИ должен сделать по порядку? Роль, рынок и обязательные требования передавайте заново с каждым брифом.
4. **Задайте результат и остановку.** Например: «Покажи новую строку, что изменилось и какой лишний профиль она может захватить. Подожди, пока я решу, запускать ли поиск».
5. **Соберите SKILL.md.** Дайте ИИ свои ответы и запрос ниже. Прочитайте черновик: узнаёте ли вы в нём собственное решение? Поправьте и попросите сохранить скилл в текущем проекте Codex.
6. **Испытайте на другой вакансии.** В новом чате вызовите скилл по имени. Дайте новый бриф и два примера. Третий, обманчиво похожий, придержите. Проверьте результат на нём сами. Если скилл ошибся, уточните правило и повторите проверку.

## Что сказать Codex

> Помоги написать мой первый скилл для сорсинга. Расспроси меня про один повторяющийся шаг, исходные данные, мою правку и признак хорошего результата. Сначала покажи, какое правило ты извлёк из примера. Спроси, хочу ли я применять его к другим вакансиям. После моего ответа собери SKILL.md с именем, описанием, порядком действий, форматом результата и местом, где нужно моё решение. Придумай проверку на другой роли.

**Как может выглядеть готовое правило.** «Когда я прошу расширить запрос, сохрани согласованные ограничения. Измени одно условие и покажи, какие слова в двух примерах теперь совпадают. Если в профиле упомянута лишь похожая задача, оставь мне вопрос для проверки. Остановись после предложения запроса».

**Как проверить дома.** Например, вы назвали скилл `my-sourcing-search`. Попросите Codex сохранить его в `.agents/skills/my-sourcing-search/SKILL.md` в папке проекта. Откройте новый чат в этом же проекте и напишите: «Используй $my-sourcing-search. Вот мой бриф, исходная строка и два фрагмента профилей». Заранее запишите, какой профиль новый запрос должен сохранить, какой добавить и какой лишний результат должен отсеяться. Первая версия готова к рабочей пробе, когда выдаёт объяснимую строку на новом брифе, сохраняет его ограничения и останавливается там, где вы договорились.

## Бриф на одну вакансию

| Вопрос к нанимающему менеджеру | Ваш ответ |
|---|---|
| Какое решение или задачу вы доверите человеку в первые месяцы? | |
| Какой пример из прошлого опыта убедит вас позвать его на встречу? Какой похожий опыт тоже подойдёт? | |
| Какие условия обязательны? Укажите географию, рабочие часы, бюджет и формат сотрудничества. | |
| В каких компаниях и командах люди уже решают такую задачу? По какому признаку это можно проверить? | |
| Какими словами человек мог описать эту работу в профиле? Какие ещё должности стоит поискать? | |
| Что можно подтвердить по открытому источнику, а что придётся спросить лично? | |

## Справочные материалы

**Выберите компанию-донора.** Запишите название команды, задачу, которая похожа на вашу, и ссылку на публикацию или вакансию, где эта задача описана. Для ориентира можно посмотреть, как устроена карта рынка. [Учебный пример talent-intel](https://github.com/SriniGundelli/talent-intel/blob/main/examples/sample-report.md)

**Сравните два запроса.** В первом укажите привычное название должности. Во втором добавьте смежную должность или попробуйте найти человека по компании и задаче. Откройте один профиль, который появился только во второй выдаче. Какая строка объясняет, почему вы бы ему написали? Что ещё нужно уточнить? [Примеры построения запросов в Sourcing Sabra](https://github.com/gehtalexey/sourcing-sabra/blob/main/skills/talent-sourcer/SKILL.md)

Для справки по синтаксису поиска: [Boolean в LinkedIn](https://www.linkedin.com/help/recruiter/answer/a524335) · [поиск по сайту в Google](https://developers.google.com/search/docs/monitor-debug/search-operators/all-search-site).
