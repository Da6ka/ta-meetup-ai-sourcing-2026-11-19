# How I teach AI to source candidates

Daria Ivanova, SPb IT Recruiter Meetup, November 19, 2026

Open the [PowerPoint with speaker notes](slides.pptx) in presenter view. As people arrive, show the [handout QR code](handout-qr.png) on slide 4. Open the [two Codex prompts](participant-guide.md#codex-demo) before the demo.

## Talk (10 minutes)

| Slides | What to show |
|---|---|
| 1-4 | Introduce yourself, outline the session and show where to get the handout. |
| 5-7 | Turn the hiring request into a Lead Data Engineer brief. Ask which decision the engineer should make independently. Mention Metaview and Juicebox briefly. |
| 8-9 | Open the [Talent Intel market map](talent-intel-lead-data-engineer.pdf). Choose Future Mind based on its client project. Discuss what a mid-level job ad can tell you about lead compensation. |
| 10-11 | Show regular LinkedIn search and Google X-ray. If the stack and experience query returns few results, start with the company and job title. |
| 12-14 | Compare the employers and read [Sasha's sample resume](sasha.md). Ask the audience to rewrite the first message using the engineer's contribution and the responsibilities of the new role. |

## Workshop (45 minutes)

| Minutes | Slides | Activity |
|---|---|---|
| 0-9 | 15-17 | Review the anonymized results. Read profiles A, B and C. Ask whom the original query would find and why C should stay out. |
| 9-24 | 18-22 | Run the Codex demo. Broaden the query for A and B, then test it on C. If Codex is unavailable, use the examples on slides 19-22. |
| 24-30 | 23-25 | Save the search verification rule. Check the quote about B's contribution and suggest a question about AI coding tools. |
| 30-32 | 4 | Return to the QR code and give participants time to open the handout. Keep slides 26 and 27 as backups. |
| 32-38 | 28-30 | Write a rule for the next search and show how to apply it to a Product Engineer role. |
| 38-45 | 31-32 | Show the [six take-home steps](participant-guide.md#my-first-sourcing-skill). Start with one criterion from a hiring brief and three anonymized profiles. Leave time for contacts and questions. |
